# 115 免费资源日报

每天一次的日报推送，搜集过去 24 小时内新出现的免费资源与 GitHub 好项目，只推新增内容。

## 搜集范围

- 免费资源：类似免费云电脑/云主机的免费套餐、免费 VPS 试用、免费 GPU 算力、免费 AI API 额度/免费 credits、免费开发工具（不限于云平台，凡是 AI 相关或电脑相关的都算）。
- GitHub 项目：GitHub trending 上新出现的值得关注的项目（AI、LLM、Agent、云、自托管等方向）。

## 筛选标准（必须同时满足才推送）

- 与 AI 或电脑相关；
- 免费（免费套餐、免费试用、免费额度）；可直接注册的在前，waitlist/邀请制的也可以列出，但必须注明“需排队/waitlist”或“需邀请”；限量名额的要标明“手慢无”；
- 过去 24 小时内新出现或新开放的；
- 每条都要有注册/项目链接，链接必须来自搜索结果或官方页面原文，绝不编造。

## 去重

已推送过的项目记入去重清单（每行一个，含名称 + 链接），只推不在清单里的；推完把新推的追加进去。

## 推送

- 每天 3 次推送到聊天（早/午/晚），中文，简洁：每条 = 名称 + 一句话介绍 + 免费内容（额度/期限）+ 链接；waitlist/邀请制的注明状态；限量或有截止时间的要标明。
- 一次检查没有符合标准的新项目时，早/午不发消息、不打扰；晚上一次无论有无都发一次消息（无新的时发“本次检查无新增”）。
- 不要替用户注册任何账号，不要索要任何账号、密码、验证码，只提供信息和链接。
