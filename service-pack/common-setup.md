# 通用搭建（所有服务共用）

## 1. GitHub Pages（网页类服务的家）

- 新建一个公开仓库 `<YOUR_GITHUB_USERNAME>/<YOUR_PAGES_REPO>`，开启 GitHub Pages（分支 main，根目录）。
- 所有网页（日报、播放器、音频中心、日程板）都发布到这个仓库，地址形如 `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_PAGES_REPO>/...`。
- 发布后 GitHub Pages 缓存可能几分钟才刷新：新页面 404 或还是旧版时，先查仓库原始文件确认已更新，等缓存刷新，不要重复发布。
- 私密内容不要放进公开仓库；日程看板这类含个人日程的页面，发布前要用户明确同意公开。

## 2. 云盘（文件/视频交付）

- 准备一个云盘文件夹放生成视频，一个放其他成品；文件夹名不要带日期时间。
- 每次交付都用云盘返回的官方查看链接，不要自己拼 URL；链接失效或打不开时，重新取一次官方链接。
- 删除用“移入回收站”而不是彻底删除，方便找回。

## 3. 推送聊天

- 约定一个用户最常看的聊天作为唯一主动推送渠道；其他聊天只做被动问答。
- 定时任务（日报、邮件简报、天气、账单检查、用量报告）都推到这个聊天，失败时要说明失败原因，不要静默。

## 4. 占位符清单（搭建时逐项填）

- `<YOUR_GITHUB_USERNAME>` / `<YOUR_PAGES_REPO>`：Pages 仓库
- `<YOUR_DRIVE_FOLDER_VIDEO>` / `<YOUR_DRIVE_FOLDER_FILES>`：云盘文件夹
- `<YOUR_GMAIL>`：收账单/简报的邮箱（如有多个，注明哪个是生活、哪个是工作）
- `<YOUR_CITY>`：天气城市
- `<YOUR_WATCHLIST>`：美股日报的自选股清单文件路径
- `<YOUR_CALENDAR_REPO>`：日程数据仓库（如用 GitHub 存日程）
