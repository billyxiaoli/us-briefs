# 播放器规范（101 / 102 / 103 及所有音频服务共用）

## 布局（自上而下，不加标题、不加开场介绍）

1. 下拉框：选音频（总页型播放器）或选章节（电子书型）
2. 主字幕框：固定高 340px，字号 19px、行高 1.55；当前句高亮，滚动规则是当前句锚定在框底部，不显示下一句，之前的句子尽量完整显示
3. 黄色翻译框：只显示当前句的翻译（英文音频配中文翻译；中文音频配英文翻译）
4. 控制行（图标，不要文字按钮，顺序固定）：时间显示 / 速度按钮 / 快进 5 秒 / 快退 5 秒 / 播放（播放最右）
5. 进度条
6. 音量按钮：放在速度按钮左边，点开滑条调 0–100%，音量全局记住
7. 状态行：加载中 / 加载失败时显示原因，不要无声停住

## 速度菜单

- 自定义按钮 + 居中弹出菜单，不要用原生下拉框
- 选项：0.75、0.8、0.85、0.9、0.95、1、1.1、1.2……2（0.75–1 按 0.05 步进，1–2 按 0.1 步进）
- 打开时当前速度滚动到菜单中央

## 音频与字幕对位

- 按句子切分：每句单独合成/截取，实测每句时长，拼成整段音频，得到每句的开始/结束时间（slots）
- 不要用未经归一化的混音方式拼句子音频，会把音量压低
- 字幕点击可跳转到该句；拖动进度条时字幕跟着对应显示

## 断点续播（按单个 MP3）

- 每个 MP3 文件单独记位置：浏览器本地存储，键 = 音频文件路径，值 = 上次播放秒数
- 打开某 MP3 时，若上次位置在 5 秒之后、且离结尾还有 5 秒以上，自动回到该位置并提示“已回到上次位置 M:SS”，不自动播放（浏览器不允许无操作自动播）
- 播完该 MP3 后清除它的位置；换设备、清缓存后位置不保留，这是正常的

## 总页型播放器（101 / 102 / 播客）

- 一个总页 + 一个下拉框，不要每个音频各给一个链接
- 新音频做好后直接加到下拉框里，链接不变；下拉框默认选中第一项
- 音频文件要干净：不要在文件中间残留拼接标签；发布前解码校验一次

## 保留规则

- 每日报播客：最多保留 3 天，到期删除并同步删掉总页里的条目
- 其他音频：一律不自动删，只由用户手动删；满 1 个月时在推送聊天逐项问用户是否删除，用户说保留的，30 天后再问
