# 105 KTV 视频制作

- 启动：发 `105` + 歌曲名或视频链接（示例：B站 BV 链接）
- 产出：KTV 成品视频（原唱分离后的人声/伴奏 + 字幕形式的 KTV 视频），云盘链接交付

## 流程（示例实现，可换等价工具）

1. 下载源视频（注意版权：只做用户自己听唱/学习用，不公开发布）
2. 人声分离：用公开的人声分离模型（示例：UVR-MDX-NET-Inst_HQ_3）分离出人声轨、伴奏轨
3. 合成 KTV 视频：伴奏 + 原唱人声轨 + 歌词字幕，校验时长与源视频一致
4. 上传云盘 KTV 文件夹，给官方查看链接；下一首由用户发歌名或链接

## 规则

- 模型文件本地缓存一次，不要每首歌重下载
- 成品先本地校验（时长、音轨数、文件可播），再交付
- 不要把 KTV 成品混进 AI 复刻视频文件夹
