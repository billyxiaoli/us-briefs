# 107 学习档案

- 启动：发 `107` + 试卷照片（一套试卷的所有照片）
- 产出（按打印准备）：PDF 原卷 + Word 版电子文本 + Word 版错题库 + Word 版考点总表；云盘链接交付，不要给 Markdown 当成品

## 流程（每套试卷）

1. PDF 归档：一套试卷的所有照片按顺序放进一个 PDF；每页 A4——单张 A4 照片一页一张，大开页拆成两页 A4
2. OCR/电子文本：读出题目、学生答案、老师红批；认不出的手写标 `[?]`，不要猜
3. 错题识别：以老师红批为准；如卷首订有标准答案，一并识别；没有明确红批的题，标为“助理自查、待家长核对老师批改”，不要冒充已确认错题
4. 考点总表：按考点分节，每考点一节，配例题（例题优先取自试卷；试卷原题没做或条件不全时，用明确标注的通用例题）
5. Word 格式：A4、宋体、标题/列表规范、考点总表用真正的 Word 表格
6. 错题库按科目累计，不要每套试卷另起一套库

## 规则

- 不要另存一份原照片档案：照片只转 PDF
- 不要在聊天里不必要地重复孩子的全名、学校
- 本地 Markdown 只当再生源，不当交付物
