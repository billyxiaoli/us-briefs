# 103 中文电子书 -> 中文音频 + 中英滚动字幕

- 启动：发 `103` + 中文 .txt 文件
- 产出：中文朗读播放器；主字幕中文逐句滚动、当前句高亮且锚定在框底部，下方黄框只显示当前句英文翻译；控制行与速度菜单同 player-spec.md

## 流程

1. 读 .txt，按句子切分（去掉纯分隔线、无意义空行）
2. 中文女声/男声朗读，逐句实测时长，拼成整段音频，做 slots（含每句英文翻译）
3. 长文本按章节分播放器，每章一个页面；总页/音频中心里登记每一章
4. 音频文件发布前解码校验，文件中间不要残留拼接标签

## 规则

- 主字幕必须是中文，英文只出现在下方黄框的当前句，不要把全文翻译铺在页面上
- 章节划分按原文章节，不要按固定字数硬切
- 保留：不自动删，满 1 个月问用户（见 player-spec.md）
