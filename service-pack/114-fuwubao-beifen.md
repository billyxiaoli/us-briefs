# 114 服务包备份

- 启动：发 `114` 可手动触发一次同步；平时每周一 09:00 自动跑一次
- 产出：服务包文件夹同步到 GitHub，朋友拿到的包始终是最新版

## 规则

- 同步范围：本地服务包文件夹里的所有文件，对应 GitHub 仓库 `<YOUR_PAGES_REPO>` 的 `service-pack/` 文件夹
- 逐个文件比对：只发布新增或内容变化的文件；不要删除 GitHub 上本地没有的文件；不要改动仓库里的其他文件夹
- 同步前检查：不要把凭证、卡号、账单金额、孩子信息、业务往来等私密信息写进包里；发现私密内容就跳过该文件并在报告里说明
- 报告规则：有文件更新时，告诉用户更新了哪几个文件；没有变化时保持静默，不要发消息；同步失败时，告诉用户失败原因和哪一步失败
