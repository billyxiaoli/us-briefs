# 101 中文音视频 -> 英文音频 + 中英滚动字幕

- 启动：发 `101` + 视频链接或视频文件
- 产出：英文配音播放器，总页下拉框里选音频；主字幕英文滚动，下方黄框只显示当前句中文翻译
- 操作与 102 完全一样，区别只在源语言：101 的源是中文，102 的源本身就是英文

## 流程

1. 拿到源视频/音频，提取原声与原字幕（如无字幕先转录）
2. 按句子翻译成英文，女声/男声按句交替配音（不要用同一个人从头读到尾）
3. 按 player-spec.md 拼音频、做 slots、做总页播放器
4. 新音频加到总页下拉框最前面，链接不变；同时登记到音频中心和保留登记表

## 规则

- 原声视频本身是英文的不要走 101，走 102
- 配音只配英文，不要保留中文原声混音
- 长视频按段分节，每节一个 MP3，总页下拉框里每节一项
- 保留：不自动删，满 1 个月问用户（见 player-spec.md）
